# Letter Griddle Mini — Duplicate Word Tracker

This file tracks words that intentionally appear more than once in the `miniPuzzles` array, paired with a different category/hint each time. Since Mini has players worldwide, repeats are fine — this is just a quick-reference so you always know at a glance which words are reused and why.

**How to use this:** Whenever you add a new batch of puzzles, cross-check new words against the master word list (or this tracker) before adding. If a word already appears, it's not an error — just log it here.

## Process for Future Batches

2. Check each against the **Master Word List** above
3. If it's new → add to Mini rotation as usual
4. If it's a repeat → **you now allow these!** Just log it in the "Confirmed Duplicates" table with both categories
5. Update the Master Word List with the new additions
